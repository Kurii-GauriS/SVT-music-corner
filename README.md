# 💎 SVT Music Corner

> **A little corner of the internet made for SEVENTEEN, music, memories, and CARATs.** 🎧💎

🔗 **Live Website:** https://svt-music-corner.vercel.app/

---

## ✨ About the Project

**SVT Music Corner** is a fan-made interactive website dedicated to **SEVENTEEN (세븐틴)** and the memories, music, and moments that make being a CARAT special.

The project combines a music-focused fan experience with a digital scrapbook aesthetic, creating a small virtual **CARATLAND** where visitors can explore SEVENTEEN, their music, memories, and fan-inspired content.

The website is designed around the idea of:

> **13 Members • 3 Units • 1 Team • Countless Memories 💎**

---

## 🌸 Features

### 💎 CARATLAND Scrapbook

A scrapbook-style page celebrating SEVENTEEN and its members.

The scrapbook includes:

* 💎 SEVENTEEN introduction
* 👥 All 13 members
* 🎤 Member roles and units
* 💖 Member-inspired messages
* 📸 Visual scrapbook elements
* ✨ Decorative animations and fandom-inspired styling

**Scrapbook:**
https://svt-music-corner.vercel.app/scrapbook.html

---

### 🎵 Music Corner

A music-focused section created around the songs and sounds associated with SEVENTEEN and the CARAT experience.

The goal is to make the website feel less like a traditional information page and more like a **personal digital music corner**.

---

### 🎧 Spotify Section

A dedicated section for discovering and enjoying SEVENTEEN's music through Spotify.

---

### 📖 Digital Scrapbook

A virtual scrapbook experience designed to feel like flipping through a collection of memories.

It combines:

* Photos
* Music
* Memories
* Decorative elements
* Fan-made content
* SEVENTEEN-inspired visuals

---

### 💗 Photocard Binder

A digital **photocard binder-style section** inspired by the way CARATs collect and organize photocards.

The feature is designed to recreate the feeling of having a personal virtual collection.

---

### 💎 SEVENTEEN Section

A dedicated section introducing the members of SEVENTEEN.

SEVENTEEN consists of:

**13 Members • 3 Units • 1 Team**

The website presents members across the:

* Hip-Hop Team
* Vocal Team
* Performance Team

---

### 🎬 Going Seventeen

A dedicated section inspired by **Going Seventeen**, SEVENTEEN's variety/content universe.

It gives the website another way to explore the group's content beyond music.

## 🎨 Design Concept

The website follows a **digital scrapbook + music diary** aesthetic.

The visual direction was inspired by:

* 💎 CARAT aesthetics
* 🎧 Music players
* 📖 Scrapbooks
* 📸 Photo collections
* 💗 Fan-made websites
* ✨ Digital memories
* 🎀 Cute decorative UI elements

The intention was to make the site feel like a **personal fan-made corner rather than a standard portfolio website**.

## 💻 Running Locally

Clone the repository:

```bash
git clone <YOUR-GITHUB-REPOSITORY-URL>
```

Move into the project directory:

```bash
cd svt-music-corner
```

Then open the project in VS Code:

```bash
code .
```

Since this is primarily a front-end website, you can run it using **VS Code Live Server** or another local development server.
